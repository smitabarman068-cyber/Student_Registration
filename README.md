# Student Registration System

## Project Description
A simple and responsive Student Registration System developed using HTML, CSS, Bootstrap 5, and JavaScript.

This project allows users to manage student details through an easy-to-use registration form.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Local Storage

## Features
- Student registration form
- Form validation
- Add student details
- Edit student details
- Delete student details
- Store data using Local Storage
- Responsive design

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
